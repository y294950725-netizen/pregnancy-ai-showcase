PART 1 · 核心功能

孕期全场景智能服务

从日常营养到紧急就医，覆盖孕妈最关心的每一个环节

🥗

1饮食计划

根据孕周、BMI、孕吐情况个性化生成每日营养方案。AI 医生提供专业进食顺序建议， 并定制含早/午/晚餐及加餐的完整食谱，精确到食材用量与烹饪方式——让孕妈「长胎不长肉」。

📋

2报告解读

拍照或上传孕检报告（如 B 超单），AI 自动识别并用通俗语言解读检查结果， 判断胎儿发育情况并给出专业建议。支持隐私保护，让孕妈安心使用。

🚑

3就医计划 + 紧急干预

当孕妈描述腹痛、出血等异常症状时，AI 实时评估风险等级。高危情况立即触发紧急干预， 自动生成「就医小抄」——涵盖基本情况、核心症状、既往病史，帮孕妈在紧张时刻高效就医。

🛍️

4个性化商品推荐

AI 医生从对话中提取专业筛选标准（如「柠檬酸钙 + 维生素 D3」），同步给推荐助手「点点」， 从「专业对齐」和「场景匹配」两个维度智能推荐——实现从健康咨询到精准消费的闭环。

PART 2 · 评测体系

Agent 时代的评测新范式

从「答案评测」走向「轨迹评测」
构建系统体检与持续监护体系

📊

评测链路闭环

传统评测 = 期末考试，Agent 评测 = 定期系统体检 + 路径审查 + 长期监护。 涵盖评测对象、空间、指标、方法、节奏、组织方法论六大维度变化， 构建从「定场景 → 定理想 → 定评估链路 → 接入自动化 → 持续回归」的完整闭环。

PART 3 · 底层能力

安全可靠的 Agent 底座

主动管理、记忆机制、谄媚治理
让 AI 真正成为值得信赖的孕期伙伴

⚡

主动管理框架

To-Do List 存的不是「明天要做什么」，而是「用户身上有哪些还没闭环的事」。 通过质变模式、阈值模式、失联唤醒三种触发机制，实现从被动响应到主动关怀的升级。

🧠

记忆机制

构建短期、长期、情感三层记忆体系，通过 Memory Orchestrator 实现意图识别、多路召回、 相关性排序与 Token 预算裁剪，配套遗忘治理机制——让 AI 真正「记住」每一位孕妈。

🛡️

谄媚监督治理

孕期智能体对话边界治理方案。通过「粗筛预警 → 监工 Agent → 干预降级」三层架构， 治理谄媚、越界、合规风险。目标：避免迎合、确保专业、保证安全、建立信赖。
